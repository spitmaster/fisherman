# Fisherman - 物体晃动监控系统

## 简介
Fisherman 是一个基于 YOLO 技术的 Windows 平台图形化桌面应用程序，专门用于监控屏幕或指定窗口中的自定义物体晃动事件。系统支持自定义物体训练和实时监控两大核心功能。

## 功能特性
- **双核心模块**：训练模块 + 使用模块，功能明确独立
- **灵活监控范围**：支持全屏监控和指定窗口精准监控
- **自定义物体识别**：通过训练模块微调模型，适配任意检测目标
- **晃动事件检测**：精准检测物体晃动，记录时间戳和位置信息
- **多物体同时跟踪**：支持画面中多个同类型物体的独立跟踪与检测
- **数据持久化**：检测结果自动保存，支持 CSV/JSON 导出
- **实时预览**：监控画面实时显示，晃动事件实时提示
- **独立运行**：打包为独立可执行文件，无需配置 Python 环境

## 系统要求
- **操作系统**：Windows 10/11 (64位)
- **内存**：8GB RAM 或以上（推荐16GB）
- **存储空间**：10GB 可用空间
- **显卡**：支持 CUDA 的 NVIDIA GPU（可选，用于加速推理）

## 安装使用

### 方法一：直接运行（推荐）
1. 下载最新版本的 `Fisherman.exe`
2. 双击运行即可，无需安装

### 方法二：从源码运行
```bash

git clone <repository-url>

# 2. 安装依赖
pip install -r requirements.txt

# 3. 运行应用程序
python src/main.py
```

## 快速开始

### 1. 训练自定义物体
1. 打开应用程序，切换到"训练模块"标签页
2. 点击"导入图像"按钮，选择包含目标物体的图片
3. 在图像上拖动鼠标绘制边界框，标注物体位置
4. 输入类别名称（如"发卡"、"杯子"等）
5. 点击"开始训练"按钮，等待训练完成
6. 训练完成后，模型会自动保存到 `models` 目录

### 2. 监控物体晃动
1. 切换到"使用模块"标签页
2. 选择监控范围（全屏或指定窗口）
3. 加载训练好的模型文件（.pt格式）
4. 调整参数：置信度阈值、晃动阈值、帧率等
5. 点击"开始监控"按钮
6. 观察实时预览画面，晃动事件会自动记录

## 参数说明

### 监控参数
- **置信度阈值**：0.1-1.0，值越高检测越严格
- **晃动阈值**：1.0-50.0，值越低对微小晃动越敏感
- **帧率**：1-60 FPS，值越高检测越实时但消耗更多资源
- **检测间隔**：每帧检测或跳帧检测，用于性能优化

### 训练参数
- **基础模型**：yolov8n.pt, yolov8s.pt, yolov8m.pt 等
- **训练轮数**：通常50-100轮，根据数据量调整
- **批量大小**：根据GPU内存调整，默认16

## 数据导出

检测到的晃动事件会自动保存到 SQLite 数据库，支持以下导出格式：

### CSV格式
- 包含时间戳、物体类别、位置坐标、晃动强度等信息
- 适合用 Excel 或数据分析工具处理

### JSON格式
- 包含完整的检测数据，包括边界框坐标和置信度
- 适合程序化处理或数据可视化

## 常见问题

### Q1: 程序运行时提示缺少 DLL 文件？
A: 请安装 Visual C++ Redistributable：
- 下载地址：https://aka.ms/vs/17/release/vc_redist.x64.exe

### Q2: 模型训练很慢怎么办？
A: 可以尝试以下方法：
1. 减少训练图像数量
2. 降低训练轮数（epochs）
3. 使用更小的基础模型（如 yolov8n.pt）
4. 确保使用 GPU 训练（如果有的话）

### Q3: 如何提高晃动检测的准确性？
A: 建议：
1. 收集更多样化的训练数据
2. 调整晃动阈值参数
3. 确保监控画面光照充足
4. 避免背景中有相似物体干扰

### Q4: 支持哪些物体类型？
A: 支持任何可以通过图像识别的物体类型，包括但不限于：
- 小件物品：发卡、钥匙、摆件、杯子等
- 电子设备：手机、平板、摄像头等
- 生活用品：花瓶、相框、装饰品等

## 高级功能

### 多物体跟踪
系统支持同时跟踪画面中的多个相同类型物体，每个物体都有独立的 ID 和轨迹记录。

### 自定义阈值
可以根据不同的监控场景调整检测敏感度，适应各种光照和环境条件。

### 批量导出
支持按时间范围批量导出检测数据，方便进行长期趋势分析。
