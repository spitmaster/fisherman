# Fisherman - 视觉自动化程序

Fisherman是一个基于YOLOv8的视觉自动化程序，专注于监控电脑屏幕、识别特定物体并自动触发鼠标点击操作。程序提供了完整的训练、标注和识别流程，支持多任务管理和模型版本控制。

## 主要功能

- **视觉识别与自动化**：使用YOLOv8模型识别屏幕上的目标物体并自动点击
- **集成标注工具**：内置可视化标注界面，支持快速标注训练数据
- **模型训练与管理**：提供完整的训练流程，支持训练任务管理和模型版本控制
- **实时监控**：显示识别统计信息，包括识别次数、点击次数和FPS
- **可配置参数**：支持调整置信度阈值和点击冷却时间
- **任务调度**：内置任务调度器，管理训练和识别任务的执行

## 安装与依赖

### 系统要求

- Windows 10/11（推荐）
- Python 3.8-3.10
- 至少4GB内存
- 支持GPU加速（可选，需要NVIDIA显卡和CUDA）

### 安装步骤

1. 克隆项目到本地：
   ```bash
   git clone <repository_url>
   cd fisherman
   ```

2. 创建虚拟环境（推荐）：
   ```bash
   python -m venv venv
   venv\Scripts\activate
   ```

3. 安装依赖库：
   ```bash
   pip install -r requirements.txt
   ```

### 依赖库说明

- `PyQt5`：图形用户界面库
- `ultralytics`：YOLOv8模型库
- `opencv-python`：计算机视觉库
- `mss`：屏幕截图库
- `pyautogui`：自动化操作库
- `Pillow`：图像处理库
- `numpy`：数值计算库
- `sqlalchemy`：数据库操作库
- `psutil`：系统监控库

## 使用方法

### 启动程序

```bash
python main.py
```

### 训练流程

1. **创建训练任务**：
   - 在主界面点击"训练"标签页
   - 填写任务信息，包括任务名称和描述
   - 选择训练参数（置信度阈值、点击冷却时间）
   - 点击"创建任务"按钮

2. **导入训练数据**：
   - 在训练任务管理区域点击"导入数据"按钮
   - 选择包含图片的文件夹
   - 程序将自动为图片创建对应的标注文件

3. **标注训练数据**：
   - 在训练任务列表中选择一个任务
   - 点击"开始标注"按钮
   - 使用标注工具框选目标物体
   - 保存标注并继续下一张图片

4. **启动训练**：
   - 在训练任务列表中选择一个已标注完成的任务
   - 点击"开始训练"按钮
   - 程序将使用YOLOv8模型进行训练
   - 训练完成后，模型将自动保存到训练结果库

### 识别流程

1. **选择模型**：
   - 在主界面点击"识别"标签页
   - 从模型列表中选择一个已训练好的模型
   - 或点击"导入模型"按钮导入外部YOLOv8模型

2. **配置识别参数**：
   - 调整置信度阈值（0.7-0.95）
   - 设置点击冷却时间（秒）
   - 选择监控区域（全屏或自定义区域）

3. **启动识别**：
   - 点击"开始识别"按钮
   - 程序将开始监控屏幕
   - 当识别到目标时，将自动触发鼠标点击

4. **停止识别**：
   - 点击"停止识别"按钮
   - 程序将停止监控并显示统计信息

### 使用标注工具

标注工具提供以下功能：

- **鼠标操作**：
  - 左键拖动画框：标注目标物体
  - 右键点击：取消当前标注

- **快捷键操作**：
  - `S`：保存当前图片的标注
  - `D`：下一张图片
  - `A`：上一张图片
  - `Q`：退出标注工具
  - `Backspace`：删除最后一个标注
  - `R`：清空所有标注

## 技术架构

1. **训练模块**：

4. **全局支撑模块**：

## 配置说明

### 训练参数

- `confidence_threshold`：识别置信度阈值，默认0.7
- `click_cooldown`：点击冷却时间（秒），默认5
- `batch_size`：训练批处理大小，默认16
- `epochs`：训练轮数，默认100

### 识别参数

- `confidence_threshold`：识别置信度阈值，默认0.7
- `click_cooldown`：点击冷却时间（秒），默认5
- `monitor_area`：监控区域（全屏或自定义坐标）
- `fps`：屏幕截图帧率（默认20帧/秒）

## 常见问题

### 1. 程序无法启动

- 确保已安装所有依赖库（运行`pip install -r requirements.txt`）
- 检查Python版本是否符合要求（3.8-3.10）
- 确保系统已安装Visual C++ Redistributable

### 2. 识别精度低

- 增加训练数据量
- 提高标注质量
- 调整置信度阈值
- 增加训练轮数

### 3. 程序运行缓慢

- 关闭其他占用资源的程序
- 减少监控区域大小
- 降低截图帧率
- 确保系统内存充足

### 4. 无法点击目标

- 检查监控区域设置是否正确
- 调整置信度阈值
- 检查训练模型是否准确

## 开发说明

### 代码结构

项目采用模块化设计，各功能模块相互独立：

- `fisherman.training`：训练相关功能
- `fisherman.training_result`：训练结果管理
- `fisherman.recognition`：识别相关功能
- `fisherman.gui`：用户界面
- `fisherman.global_support`：全局支撑功能

### 扩展功能

如需扩展功能，可在相应模块中添加新方法：

1. **添加新的训练算法**：修改`training_manager.py`
2. **添加新的识别策略**：修改`screen_recognition.py`
3. **更新用户界面**：修改`main_window.py`
4. **添加新的数据存储方式**：修改`database.py`

### 编译成可执行文件

可以使用PyInstaller将程序编译成可执行文件：

```bash
pip install pyinstaller
pyinstaller --onefile --windowed main.py
```
