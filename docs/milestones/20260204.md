### T1 输入草稿 — SPEC §2.7.x 与 §3.3.x 增补(待 T1 执行时最终化)

> 来源:orchestrator B 段。本块是参考草稿,不是 SPEC 正文;T1 执行时由 fisherman-orchestrator 写入 [../SPEC.md](../SPEC.md) 并按 SPEC 整体文风微调。

#### 草稿:SPEC §2.7.x 多目标识别策略(P0-1)

- **MultiTargetStrategy 接口**:输入 detections + context(last_click_*, history),输出 0..N 个目标
- **内建策略**:
  - `TopConfidence(n=1)`:置信度 Top-N(默认,n=1 等价当前行为)
  - `RoundRobin`:按 class_id 或位置分桶,每帧切换下一桶
  - `GeometryFilter`:基于 ROI / 距屏幕中心 / 距上次点击的距离规则过滤
- **策略组合**:Filter → Selector 两段式,Filter 可串联
- **持久化**:`recognition_tasks` 新增 `strategy_name`(VARCHAR)、`strategy_params`(JSON TEXT),无破坏性迁移(可空,默认 `TopConfidence`)
- **运行期切换**:UI 改策略不停任务,通过线程安全的 setter 注入

#### 草稿:SPEC §3.3.x 识别错误分类与重试

- **可恢复错误**(自动重试 ≤ N 次,日志 WARNING):
  - 单次截图失败(mss 偶发)
  - 单次推理超时 / OOM 自恢复
  - 点击越界(坐标超出屏幕)→ skip 本次
- **不可恢复错误**(停任务 + ERROR 级日志 + UI 弹提示):
  - 模型加载失败
  - 连续 K 次截图/推理失败(K 可配,默认 5)
  - 监控区域无效
- 所有错误路径**禁裸 print**,统一 `logger.warning/error`;关键事件入 `recognition_logs` 表
