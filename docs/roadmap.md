## 进行中

### M5 自动钓鱼 🚧 设计阶段(2026-05-25 启动)

**背景**:WoW 钓鱼是固定流程(抛竿 → 等浮漂落水 → 等鱼上钩浮漂下沉 → 右键拾取 → 上鱼饵 → 继续抛竿),可全自动化。引入独立 FishingTab,F11 启动 / F12 停止死循环,内部状态机串联六步骤(预备等待 / 钓鱼前准备 / 抛竿 / 抛竿后等待 + 检测超时 / 触发后等待 + 右键拾取 / 钓鱼后处理),位移检测复用 M4 已调到位的 tracker。

**设计落点**:SPEC [§2.14](./SPEC.md#214-钓鱼标签页fishingtab-待开发m5) FishingTab 功能规格 + [§5.5c](./SPEC.md#55c-钓鱼循环状态机fishingloop) 状态机/线程模型。
**详情**:[milestones/20260204.md#m5--自动钓鱼--设计阶段](./milestones/20260204.md#m5--自动钓鱼--设计阶段)。

- 死循环六步骤(按键输入接受 `keyboard` 库所有字符串,前/后处理可空)
- F11/F12 全局热键(复用图库 keyboard 模式,响应 ≤ 50ms)
- E2E 游戏内验证(连续 10 轮无中断;白天 / 夜晚 / 不同水域)
- 初版不入 DB,纯内存统计
