# 01 项目概述

## 1. 项目定位

Fisherman 是一款运行在 Windows 桌面上的视觉自动化工具，基于 YOLOv8 目标检测模型，提供 **数据标注 → 模型训练 → 屏幕识别 → 自动点击** 的一站式闭环能力。用户无需编写代码即可通过图形界面训练自己的识别模型，并用模型实时监控屏幕区域、识别目标、自动触发鼠标点击或自定义脚本。

## 2. 目标用户与场景

- 游戏辅助开发者：识别游戏内资源、怪物、提示等并自动交互
- 自动化办公人员：识别特定控件/图标并执行重复操作
- 计算机视觉初学者：低门槛体验完整的 YOLO 训练与推理闭环

## 3. 核心功能清单

| 功能域 | 功能点 |
|--------|--------|
| 训练集管理 | 新建 / 删除训练集；导入图片（复制方式）；展示总图数 / 已标注数 / 进度 |
| 图像标注 | Qt 图形化标注器；矩形框绘制；导出 YOLO 格式标注；标注验证 |
| 模型训练 | 训练参数配置（epochs、batch_size、imgsz、模型类型）；实时日志输出；训练中断/恢复；结果自动归档 |
| 训练结果 | 模型列表与版本；导入/删除/打开目录；模型对比（规划中） |
| 屏幕识别 | 全屏或 ROI 区域监控；YOLO 推理；置信度阈值调节；FPS / 识别次数统计 |
| 识别测试 | 实时查看识别结果、BBox 与置信度，用于验证模型效果 |
| 识别操作 | 在识别基础上自动触发点击；支持点击冷却时间；支持自定义脚本执行 |
| 日志与数据库 | 训练/识别日志落库；运行日志文件；提供日志查看窗口 |
| 任务调度 | 训练、识别任务的统一调度器，避免资源冲突 |

## 4. 非目标（Non-Goals）

- 不做 Web/云端推理服务，仅作本地桌面程序
- 不做分布式训练（当前默认 CPU 单机训练）
- 不提供从零开始的模型结构设计，基于 YOLOv8 预训练权重微调

## 5. 技术栈摘要

- 语言：Python 3.8+
- GUI：PyQt5
- 深度学习：PyTorch（CPU）、Ultralytics YOLOv8
- 计算机视觉：OpenCV、mss（屏幕截图）
- 自动化：pyautogui（鼠标点击）
- 数据库：SQLite + SQLAlchemy ORM
- 打包与启动：`启动_Fisherman.bat`（Windows）、`main.py`（跨平台入口）

## 6. 运行环境

- 操作系统：Windows 10/11 64 位
- 内存：≥ 4 GB，磁盘 ≥ 2 GB
- 依赖：Visual C++ Redistributable 2015-2022（PyTorch 需要）
- Python：3.8 及以上

详见 [08_tech_stack.md](08_tech_stack.md)。

## 7. 项目亮点

- **闭环完整**：从数据到模型再到实时推理全流程可视化
- **模块化架构**：gui / training / recognition / global_support 解耦，易维护
- **UUID 规范**：训练集与数据库主键均使用 UUID，避免路径与 ID 冲突
- **实时监控**：训练和识别进度实时回调至 UI
- **统一调度**：任务调度器串行化重资源任务，避免 GPU/CPU 竞争
