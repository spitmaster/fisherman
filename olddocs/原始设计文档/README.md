# Fisherman 设计文档索引

本目录包含 Fisherman 视觉自动化程序的完整设计文档。文档从不同维度描述系统的功能、架构、数据与流程，供开发者、维护者快速理解系统全貌。

## 项目简介

Fisherman 是一个基于计算机视觉（YOLOv8）的桌面自动化程序。它让用户通过图形界面完成"数据标注 → 模型训练 → 屏幕识别 → 自动操作"的完整闭环，典型应用场景为游戏、自动化办公等需要识别并点击屏幕特定目标的任务。

## 文档维护原则

1. 与代码同步：新增或重构模块时同步更新对应章节
2. 保持简洁：单文件聚焦单主题，避免跨文档重复
3. 事实优先：优先记录"是什么/怎么做"，而非"将来怎样"
