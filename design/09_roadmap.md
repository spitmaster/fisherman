## 2. 已完成要点

- 训练闭环：新建 → 导入 → 标注 → 训练 → 产出模型
- UUID 化的训练集目录与数据库主键
- 主窗口重构：单文件从近千行精简到约 160 行
- Tabs 解耦：训练、训练结果、识别测试、识别操作、设置独立成文件
- 标注器：Qt 图形化，支持 YOLO `.txt` 导出与基本校验
- 屏幕识别：全屏 / ROI、置信度阈值、点击冷却、实时统计
- 任务调度：训练与识别不会并发抢占 CPU

## 3. 进行中 / 优化项

- 错误处理与重试机制不足

- FPS / 延迟性能调优

### 3.2 training_result
- 模型对比（mAP / loss 曲线对比）
- 模型导入/导出流程闭环

### 3.3 training
- `yolo_trainer`：早停、更多超参数暴露

- 训练结果页面的指标图表
